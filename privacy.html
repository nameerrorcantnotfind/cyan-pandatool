Privacy Policy — Cyan Panda Tool

Effective date: 24 October 2026 · Official site: nameerrorcantnotfind.github.io/cyan-pandatool

1. What Cyan Panda Tool is

Cyan Panda Tool is a personal fan-management assistant for a single TikTok creator. It helps the creator organize fan information, review AI-suggested replies before sending, and learn the creator's conversation style from chat history.

2. Data we access

When the creator signs in with TikTok (Login Kit), the tool requests only the scopes shown on the TikTok authorization screen: user.info.basic (display name, avatar, open ID), user.info.stats (follower statistics) and video.list. The tool does not request access to private messages beyond what the creator manually provides inside the tool.

3. Where data is stored

Fan lists, notes and settings created in the tool are stored in the creator's own browser storage (localStorage) and, if the creator configures it, in the creator's own Supabase project. Data is not stored on any Cyan Panda Tool server — the tool is a static web application.

4. How data is used

Data is used solely to operate the tool for the signed-in creator: displaying fan lists, personalizing reply suggestions, and computing conversation statistics. We do not sell, rent, or share personal data with third parties for advertising.

5. Tokens and credentials

OAuth access tokens are stored only in the creator's browser and expire according to TikTok's policy. The TikTok Client Secret is never embedded in the public web application; when a backend is used, token exchange happens through a server-side function controlled by the creator.

6. Data deletion

The creator can delete all locally stored data at any time by clearing the browser's site data for this domain, disconnecting the TikTok account inside the tool (which removes the stored token), or deleting rows in their own Supabase project.

7. Contact

For privacy questions, contact the developer through the official website above.
